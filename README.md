# Jigsaw Puzzle

เกมต่อภาพจิ๊กซอว์ 20 ชิ้น สร้างด้วย HTML, CSS และ JavaScript โดยใช้ภาพ `car.jpg`

## วิธีเล่น

1. เปิด `index.html` ด้วยเว็บเบราว์เซอร์
2. ลากชิ้นส่วนจากแถบด้านล่างไปวางใกล้ตำแหน่งที่ถูกต้องบนภาพ
3. กด **เริ่มเกมใหม่** เพื่อสุ่มชิ้นส่วนและเริ่มจับเวลาใหม่

เกมแบ่งภาพเป็น 5 คอลัมน์ × 4 แถว รองรับการลากด้วยเมาส์และหน้าจอสัมผัส บนเดสก์ท็อปจะแสดงกระดานและถาดชิ้นส่วนไว้ข้างกัน โดยจัดถาดเป็น 5 คอลัมน์ × 4 แถวเพื่อให้เห็นครบทั้ง 20 ชิ้น
